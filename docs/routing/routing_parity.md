## 3. Summary

Structure and rule order are in parity almost everywhere: the flat selector (bar one rule), the wrap/measure rules, the Möbius per-attribute matrix (centres gate, spectral gate, comb restriction, L = 0 short-circuits), the wrapped Gaussian, the nested plan/enumeration race, the eval selector, the sweep chooser, the entropy dispatchers, and `explain_dispatch`'s (shared) infidelity all match predicate-for-predicate, with only fitted constants and memory budgets differing.

The gaps that change numbers for the same input are: the Python nested path ignoring a per-call `truncation_sigmas` (A-1), Python dropping `wrap` on the nested-MA flat branch and on Rényi-2 flat attributes (A-2, A-3), MATLAB honouring `method='mobius'` on ordered attributes in MA evaluation where Python raises (A-4), the Rényi-2 r = 1 relative convention (A-5), MATLAB's single-multiset-corner-only non-finite eval fallback (A-7), batched-raw kernel covariance (A-8), and `kernel_precision` honoured on different routes (A-9). Route-only gaps: MATLAB's list forms dropping `method`/ts (A-10, A-11), the Python-only working-set guard (A-12), `method='factored'` (A-13), and the reciprocal raw-MA-list fast paths (A-14).
