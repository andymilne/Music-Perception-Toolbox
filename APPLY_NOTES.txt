APPLY NOTES — full uncommitted set on top of the SA-line HEAD (75041df).

Adds, on top of the previously delivered hybrid spectral EVALUATION strategy
(both languages), a cost-gated spectral branch for the relative-mode INNER
PRODUCT, Python only:

  mpt/_tensor/cosine.py   _spectral_rel_inner_matrix() + gate in
                          _ma_per_attr_inner_matrix_rel(), r = 2..4
  tests/test_spectral_rel_ip.py (new, 6 tests)

Correctness: agrees with the grid path it replaces at ~3e-13 for r = 2, 3, 4 in
both periodic and non-periodic modes, absolute scale included (constant
C_r = r (sigma^2 dxi)^(r-1), derived and verified with no fitted parameters).

Cost gate: the grid path costs K^2 per event pair while the branch costs the
(r-1)-dimensional mode grid, so the branch is taken only while the grid stays
under 1000 * K^2 * n_x * n_y, plus a hard 4e6-point memory cap. Calibrated
against measured wall times over sigma/P in 0.0025..0.05, K in 4..100, and
event counts 1..30; without the gate the small-sigma/P corner regressed up to
12x. With it, measured gains run from ~1.3x to ~1400x and no measured cell
regresses. Full Python suite green, 90 files.
